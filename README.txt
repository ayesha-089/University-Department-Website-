UNIVERSITY DEPARTMENT WEBSITE
=============================

PROJECT STRUCTURE
department/
  index.html
  about.html
  programs.html
  faculty.html
  courses.html
  admissions.html
  news.html
  contact.html
  assets/
    style.css
    script.js
    images/
      campus.svg
      lab.svg
      logo.svg

HOW TO RUN
1. Extract the ZIP file.
2. Open the department folder.
3. Double-click index.html, or open it with VS Code.
4. For VS Code, you may use the Live Server extension.

FEATURES
- Eight linked HTML pages.
- Shared navigation on every page.
- Semantic HTML5 landmarks and headings.
- Faculty and courses tables use thead and tbody.
- Meaningful images include descriptive alt text.
- Skip-to-content link and visible keyboard focus.
- Responsive CSS for desktop, tablet, and mobile.
- Contact form demonstration with accessible status message.

IMPORTANT
This is a sample academic website. Faculty names, email addresses,
course codes, office information, and announcements are illustrative.
Replace them with verified official department information before publishing.

HTML VALIDATION
You can validate each HTML page at https://validator.w3.org/nu/
by uploading the extracted HTML files or checking each page URL.
